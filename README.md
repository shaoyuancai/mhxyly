# 梦幻洗宠模拟

一款以 **召唤兽栏** 为中心的《梦幻西游》风格召唤兽模拟器：**兽栏 · 洗炼 · 打书 · 炼妖 · 图鉴 · 记录**。

纯静态，无服务器、无构建步骤、无外部图片或第三方库。召唤兽立绘全部由 SVG 程序生成，音效由 WebAudio 实时合成。

> **本版不记录任何价格或花费。** 洗炼只统计道具使用次数，打书只统计每本兽决的使用次数，炼妖只统计次数。
>
> 同人练习作品，与网易 / 《梦幻西游》官方无关。

---

## 运行

**本文件夹已经包含游戏运行所需的全部文件**，可以直接复制、移动到任意位置。

双击本文件夹中的 `index.html` 即可开始。

如果希望使用本地服务器，在本文件夹内执行：

```bash
python -m http.server 8080
# 访问 http://127.0.0.1:8080/
```

推荐 Chrome / Edge，桌面与手机均可。

## 核心流程

### 1. 召唤兽栏

- 「兽栏」是唯一的召唤兽仓库。
- 点击「增加召唤兽」打开万灵谱，选择种类后随机生成一只召唤兽加入兽栏；不消耗道具。
- 兽栏最多 30 只，点击任意召唤兽会弹出操作菜单：
  - **洗炼**：带着这只召唤兽进入洗炼台。
  - **打书**：带着这只召唤兽进入打书界面。
  - **炼妖**：以这只召唤兽为主宠进入炼妖界面。
  - **删除**：从兽栏移除，不可恢复。
- 如果直接从顶部进入洗炼 / 打书 / 炼妖，而没有选中兽栏召唤兽，会先显示「请先从召唤兽栏选择」的提示。

### 2. 洗炼

- 洗炼作用于当前选中的兽栏召唤兽。
- 每次重掷：
  - 六项资质：攻击、防御、体力、法力、速度、躲闪，按官方区间分 **21 档**随机。
  - 成长：区间内 **5 档**随机。
  - 技能：从必带技能 + 可选技能池抽取，数量概率为  
    `1 格 18% / 2 格 30% / 3 格 26% / 4 格 16% / 5 格 7.5% / 6 格 2.5%`。
- 可以使用 1 / 5 / 10 / 50 连洗，设置目标技能数；达到目标会提前停止。
- 结果与洗炼前逐项对比：绿色提升、红色下降、被顶掉的技能单独标出。
- 满意就「替换当前」，更新兽栏中的这只召唤兽；不满意「放生」，保留原样。
- 批量洗炼可自动保留更高评分。
- 洗炼道具按参战等级与是否变异自动选择：

  | 道具 | 适用 |
  | --- | --- |
  | 金柳露 | 普通召唤兽，参战等级 < 95 |
  | 超级金柳露 | 普通召唤兽，参战等级 ≥ 95 |
  | 净瓶玉露 | 变异洗炼，参战等级 < 95 |
  | 超级净瓶玉露 | 变异洗炼，参战等级 ≥ 95 |
  | 泡泡祈福石 | 泡泡 / 泡泡灵仙 |

- 界面只显示「累计使用 N 次」「本次消耗 ×N」，不显示价格。
- 变异洗炼会改变配色与收藏标记，不额外提升资质。

### 3. 打书

- 作用于当前选中的兽栏召唤兽。
- 从 207 本兽决中选择；界面显示每本兽决的**累计使用次数**，不显示价格。
- 参战等级 < 125 时技能格上限为 4；≥ 125 时为 5；总技能栏最多 12。
- 技能数低于上限时，每次打书有 **25%** 概率开出新格；否则随机顶掉一个技能。
- 互斥技能（低级/高级同名、神佑与鬼魂、否定信仰与精神集中等）会被新书直接顶掉。
- 记录会按书统计，例如「永恒 ×2」「高级必杀 ×1」。

### 4. 炼妖

- **主宠与副宠都必须从兽栏中选择**。
- 90% 成功：
  - 45% 继承主宠造型，45% 继承副宠造型。
  - 技能：双亲技能池中每个技能 **30%** 概率继承；结果造型的必带技能必定保留，最多 12 格。
  - 成长：双亲成长均值 × `0.96 / 0.98 / 1.00 / 1.02`。
  - 资质：双亲资质均值 × `0.70 ~ 1.10`，最低 800。
- 10% 失败：变成大海龟、泡泡或野生召唤兽。
- 炼妖消耗两只召唤兽，**结果自动收入召唤兽栏**，可以继续洗炼或打书。
- 不记录价格，只记录炼妖次数。

### 5. 记录

- 「洗炼道具用量」：金柳露、超级金柳露、净瓶玉露、超级净瓶玉露、泡泡祈福石各用了多少次。
- 「兽决用量」：每本兽决用了多少次。
- 「操作记录」：增加、删除、洗炼、打书、炼妖的时间与内容。
- 成就、名人堂、图鉴收集进度。
- 存档导出 / 清空。

## 评分与评级

```text
评分 = 六项资质平均值 + 成长 × 12000 + 技能数 × 18000
```

| 评级 | 名称 | 达成度 |

| SSS | 天授 | ≥ 93% |
| SS | 绝品 | ≥ 87% |
| S | 上品 | ≥ 80% |
| A | 良品 | ≥ 71% |
| B | 中品 | ≥ 60% |
| C | 凡品 | < 60% |

## 数据与设计说明

- 召唤兽数量：213 条原始记录，按名字去重后 203 种。
- 资质、成长区间、必带/可选技能来自《梦幻西游》官方宠物站公开资料。
- 神兽不参与洗炼，因此未收入操作列表。
- 立绘不使用任何图片素材：按名称匹配兽形、鸟形、龙形、蛇形、龟形、蛙形、鱼形、虫形、花灵、鬼形、人形、石灵、法器 13 类模板，再按五行与个体哈希生成配色、耳角、鬃毛、尾巴、花纹、配饰。
- **没有价格系统**：不记录花费、不显示单价、不要求购买道具；只统计道具与兽决的使用次数。
- 没有繁殖，只做「兽栏 + 洗炼 + 打书 + 合宠（炼妖）」。
- 存档保存在浏览器 localStorage，键名 `mh_pettrain_v2`；旧版 `mh_pettrain_v1` 会在首次打开时自动迁移兽栏与收集数据。
